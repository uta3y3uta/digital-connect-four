# デジタル コネクトフォー

小学校の授業で使うデジタル版「コネクトフォー（4目並べ）」です。プロジェクター投影や1人1台端末（GIGA端末）での利用を想定しています。**対戦後の感想戦（振り返り）**を簡単にできるよう，戻る／進む／最後まで進むボタンを常時用意しています。

## 特長

- **単一HTMLファイル**：`index.html` をブラウザで開くだけで動作（外部依存なし）
- **配色テーマ10種**：教室の雰囲気に合わせて切り替え可能（設定はブラウザに保存）
- **2つの入口**
  - **ベーシックルール**：標準7×6 の1対1
  - **アレンジルール**：フィールド広さ（5×4〜10×8），人数（2〜8人），ポイント制，凸凹フィールドを自由に組み合わせ
- **ポイント制（どんでん返しあり）**
  - マスごとにランダムな得点（+20／+30／-10 など）
  - 段ごとの基本点（1段目+10／2段目-10／3段目+20／4段目-20…）
  - 4目揃えで +100 ボーナス
  - 「揃えたのに総得点で負け」の知的な駆け引きが起きる
- **凸凹フィールド戦**：障害マスがランダム配置される
- **多人数対戦**：3人（三つ巴），4人（四つ巴），最大8人まで
- **感想戦**：対戦中も対戦後も「戻る・進む・最後まで進む」が使える。途中で別の手を打つと分岐する

## 使い方

1. `index.html` をブラウザ（Chrome / Edge 推奨）でダブルクリック
2. 入口から **ベーシックルール** または **アレンジルール** を選ぶ
3. 列をクリック／タップしてコマを落とす
4. 4つ並べたら勝ち（ポイント制では総得点で勝負）
5. 下部の **配色** で色を切り替え可能
